# 산업연관표 분석 웹앱

## 1. 웹앱 개발 목적

본 웹앱은 산업조직론 수업에서 학습한 산업연관표를 활용하여 산업 간 거래 관계를 파악하고, 특정 산업의 최종수요 증가가 국내 경제에 미치는 파급효과를 분석하기 위해 구축하였다.

## 2. 사용 데이터

- 자료 출처: 한국은행 산업연관표
- 기준 연도: 2023년
- 가격 기준: 생산자가격
- 산업 분류: 기본부문(380개 부문)
- 금액 단위: 백만원

## 3. 웹앱 사용 방법

### 3-1. 원자료 탐색

1. '기본부문 불러오기' 버튼을 클릭한다.
2. 분석 목적에 맞는 산업연관표 시트를 선택한다.
3. 행 이름 검색을 통해 분석하고자 하는 산업을 검색한다.
4. 행 선택에서 해당 산업을 선택한다.
5. 열 검색을 활용하여 관련 산업의 거래액 또는 계수를 확인한다.

### 3-2. 국내 생산물 최종수요 증가 시뮬레이션

1. 산업 검색을 통해 분석 대상 산업을 검색한다.
2. 해당 산업을 선택하고 최종수요 증가액을 입력한다.
3. '시나리오에 추가' 버튼을 클릭한다.
4. '파급효과 계산' 버튼을 클릭한다.
5. 생산유발액, 수입유발액, 부가가치유발액 및 산업별 분석 결과를 확인한다.
6. 필요한 경우 전체 산업의 분석 결과를 CSV 파일로 다운로드한다.

## 4. 산업연관분석 방법

- 수입거래표: 수입 상품이 국내 각 산업에 얼마나 사용되는지 분석한다.
- 생산유발효과: 최종수요 증가에 따라 국내 산업의 생산이 얼마나 유발되는지 분석한다.
- 수입유발효과: 최종수요 증가에 따라 수입이 얼마나 유발되는지 분석한다.
- 부가가치유발효과: 최종수요 증가에 따라 국내 부가가치가 얼마나 창출되는지 분석한다.

## 5. 분석 활용 예시

자동차 산업의 산업 간 연관관계와 경제적 파급효과를 분석한다.

- 분석 대상: 자동차 부분품 및 승용차
- 원자료 탐색: 수입거래표를 활용한 자동차 부분품의 산업별 사용 구조 분석
- 시뮬레이션: 국내 생산 승용차의 최종수요가 100억 원(10,000백만원) 증가하는 상황을 가정
- 분석 지표: 생산유발액, 수입유발액, 부가가치유발액

이를 통해 완성차 산업과 자동차 부분품 산업 간의 연관관계 및 최종수요 증가에 따른 경제적 파급효과를 파악할 수 있다.
